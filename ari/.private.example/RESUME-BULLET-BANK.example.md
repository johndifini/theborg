# Resume Bullet Bank

> Public-safe template. All examples below are synthetic and must not be treated as candidate facts.

Use this file as a curated evidence bank for tailoring resumes to specific job descriptions. Keep original resumes and other source records as the authority; this bank indexes their claims and approved variants.

## Rules

- Never add an accomplishment, responsibility, skill, or metric without a source or direct candidate confirmation.
- Preserve the meaning and scope of the underlying evidence when tailoring wording.
- Mark uncertain claims `needs-confirmation`; do not use them in an application until confirmed.
- Retain superseded material for provenance, but mark it `retired` and explain why.
- Treat every value and example in the private copy as confidential.

## Status values

- `verified` — supported by a source record or confirmed by the candidate.
- `needs-confirmation` — potentially useful, but its wording, scope, or metric requires review.
- `retired` — retained for history but not available for current applications.

## Tailoring checklist

1. Extract the job description's core outcomes, responsibilities, and required skills.
2. Select only `verified` entries supported by relevant evidence.
3. Rank entries by relevance and strength; do not optimize for keyword overlap alone.
4. Tailor wording without changing factual meaning, ownership, scale, dates, or metrics.
5. Check that selected bullets are mutually consistent with the resume's titles and chronology.
6. Preserve each selected entry's ID in working notes so the final wording remains traceable.
