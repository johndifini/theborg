# Private context example

Copy `AGENTS.example.md` to `CLAUDE.local.md` in the agent root and `WATCH-LOG.example.md` to `.private/WATCH-LOG.md`, then replace the synthetic values locally. Claude Code loads `CLAUDE.local.md` automatically; Codex reads it through the pointer in `AGENTS.md`. Both local paths are git-ignored. This example directory is public and must remain synthetic.
